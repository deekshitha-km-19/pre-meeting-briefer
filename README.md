# 🤖 PRE-MEETING BRIEFER
### Walk Into Every Meeting Prepared.

An AI-powered meeting preparation assistant built with Google Gemini.

PRE-MEETING BRIEFER helps individuals and teams prepare for meetings by analyzing agendas, uploaded documents, and background information. It transforms unstructured meeting information into clear, actionable meeting briefs.

## 🚀 Problem Statement

People often attend meetings without sufficient preparation. They may miss important background information, overlook risks, or fail to identify the right questions and decisions.

Preparing manually takes time and can lead to ineffective discussions.

## 💡 Our Solution

PRE-MEETING BRIEFER uses AI to analyze meeting information and generate structured, intelligent meeting preparation briefs.

It helps users understand what to discuss, what to ask, what risks to consider, and what decisions need to be made before entering a meeting.

## ✨ Key Features

- **AI-Powered Meeting Briefing:** Generate meeting briefs using Google Gemini.
- **Executive Summary:** Understand the meeting quickly.
- **Smart Questions:** Generate relevant questions for productive discussions.
- **Risk Identification:** Identify potential challenges and risks.
- **Expected Decisions:** Highlight decisions that may need to be made.
- **Action Items:** Organize important tasks and responsibilities.
- **Document Upload:** Upload supporting meeting documents.
- **Preparation Checklist:** Track readiness before meetings.
- **Meeting Management:** Create and manage meetings.
- **PDF Export:** Export meeting briefs for convenient sharing.
- **Demo Mode:** Explore the application with sample meeting data.

## ⚙️ How It Works

1. Create a new meeting.
2. Enter the meeting title, agenda, and relevant details.
3. Upload supporting documents.
4. Let Google Gemini analyze the information.
5. Generate an intelligent meeting briefing.
6. Review smart questions, risks, expected decisions, and action items.
7. Complete the preparation checklist.
8. Export the briefing as a PDF.

## 🧠 AI Capabilities

The application uses Google Gemini to:
- Understand meeting agendas and background information.
- Summarize important context.
- Generate useful discussion questions.

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/deekshitha-km-19/pre-meeting-briefer.git
```

### 2. Open the project folder

```bash
cd pre-meeting-briefer
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file and add the environment variables required by your application.

Example:

```env
GEMINI_API_KEY=your_gemini_api_key
SUPABASE_URL=your_supabase_project_url
SUPABASE_ANON_KEY=your_supabase_anon_key
```

Use the exact variable names expected by your application. Never commit real API keys or secret credentials.

### 5. Start the application

```bash
npm run dev
```
